# Data source and use

The bundled CSV is the IBM HR Analytics Employee Attrition & Performance sample, distributed from this [Kaggle dataset page](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset). This project includes the provided CSV as its local input. Check the upstream page's current terms and attribution requirements before redistributing the dataset in a public repository; the project does not claim ownership or grant a license to the data. The dataset is fictional/synthetic and must not be represented as real employee information.
